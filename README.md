# Rota 116 — Landing page de venda de carros

Página estática com botão de modo claro/escuro (HTML, CSS e JavaScript separados).

## Estrutura
- `index.html`: conteúdo da página
- `style.css`: estilos e cores dos dois temas (variáveis CSS)
- `script.js`: lógica do botão de tema (salva a escolha no navegador)

## Como usar
Abra o `index.html` no navegador. Para publicar no GitHub Pages: Settings > Pages > Branch `main` / pasta `/ (root)`.

## Personalizar
- Cores: edite as variáveis no topo de `style.css`.
- WhatsApp: troque `5500000000000` em `index.html` pelo seu número com DDI e DDD.
